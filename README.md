# 🎯 Delipat Lead Management System

### AI-powered lead capture, qualification, and CRM — built for the Delipat AI Engineer Internship Assessment

[![Next.js](https://img.shields.io/badge/Next.js-14-black?logo=next.js)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.3-blue?logo=typescript)](https://www.typescriptlang.org/)
[![Prisma](https://img.shields.io/badge/Prisma-MySQL-2D3748?logo=prisma)](https://www.prisma.io/)
[![Claude API](https://img.shields.io/badge/AI-Claude%203.5%20Sonnet-D97757)](https://www.anthropic.com/)

A full end-to-end lead management pipeline: a visitor submits a project inquiry through a landing page, 
**Claude analyzes their industry, budget, company size, and project description** to produce a 0–100 lead score with a Hot/Warm/Cold temperature, 
a confidence rating, and a recommended next action — all automatically, in seconds. Leads are stored in MySQL via Prisma, an acknowledgement email is sent instantly, 
and everything is visible in a live CRM dashboard where the sales team can filter, edit, and track follow-ups.

**Stack:** Next.js 14 (App Router) · TypeScript · Prisma + MySQL · Anthropic Claude API · Tailwind CSS · Nodemailer
